# Tuvio External Thermostat

Отдельная HACS-интеграция Home Assistant, которая управляет кондиционером из
официальной интеграции Tuya по внешнему датчику температуры. Алгоритм повторяет
внешний термостат из `gree_custom`.

## Как работает

Интеграция создаёт новую сущность `climate` с комнатной целевой температурой.
Физический кондиционер Tuya остаётся включённым в выбранном режиме, а термостат
переключает его между двумя уставками:

- при необходимости нагрева используется высокая активная уставка, после
  прогрева — низкая уставка ожидания;
- при необходимости охлаждения используется низкая активная уставка, после
  охлаждения — высокая уставка ожидания;
- отдельные гистерезисы задают границы включения и возврата в ожидание.

Параметры можно менять без перезагрузки через шесть сущностей `number` или через
настройки интеграции.

## Требования

- Home Assistant 2026.3 или новее;
- кондиционер добавлен официальной интеграцией Tuya и имеет сущность `climate`;
- внешний датчик имеет класс устройства `temperature`.

## Установка

1. Добавьте этот репозиторий в HACS как пользовательский репозиторий категории
   **Integration**.
2. Установите **Tuvio External Thermostat** и перезапустите Home Assistant.
3. Откройте **Настройки → Устройства и службы → Добавить интеграцию**.
4. Выберите **Внешний термостат Tuya**, кондиционер и комнатный датчик.

Значения по умолчанию совпадают с вариантом Gree: гистерезисы `0,5 °C`, нагрев
`30/16 °C`, охлаждение `16/30 °C`.

## Яндекс Умный дом и Yaha Cloud

Внешний термостат можно передать в «Дом с Алисой» как обычный термостат. В Яндексе
появятся целевая температура и кнопки **Охлаждение** / **Обогрев**. Готовый пример
настройки и порядок обновления устройств приведены в
[отдельной инструкции](docs/yandex-smart-home.md).

## Важное поведение

- Пока виртуальный термостат включён, он повторно применяет нужный режим и
  уставку после внешнего изменения сущности Tuya.
- При недоступности датчика термостат становится недоступным и не отправляет
  новые команды. Последняя уставка кондиционера сохраняется.
- Выключение виртуального термостата только освобождает управление: физический
  кондиционер сохраняет текущий режим и уставку, после чего им можно управлять
  напрямую через Tuya без вмешательства внешнего термостата.
- Все внутренние настройки хранятся в градусах Цельсия; Home Assistant выполняет
  отображение и перевод единиц для интерфейса.
